Comment l’installer en 15 secondes sur Chrome / Brave / Opera ?
  1. Décompresse le fichier

    ScanController-v1.0.zip

  2. Ouvre les extensions

    Tape chrome://extensions dans la barre d’adresse et active « Mode développeur » en haut à droite.

  3. Charge l’extension

    Clique sur « Charger l’extension non empaquetée » et sélectionne le dossier ScanController.

Brave : brave://extensions · Opera : opera://extensions

Extension pour ordinateur. Chrome sur téléphone n’accepte pas les extensions : ouvre ce lien sur ton PC ou ton Mac.
